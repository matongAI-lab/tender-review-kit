# 技术线 · 评分（专项工作指南）

## 你的任务
整理技术评分项（技术分构成），按评分组逐组列全。只列事实。

## 输入
- `<项目>.lines.txt`（按行号局部读，不全读）
- 技术评分标准的章节行号范围
- 技术 ▲ 清单（货物类技术分常是"满足每条▲得1分"累加）

## 步骤
1. Grep「技术评分 / 满分 / 得 1 分」定位技术评分章节。
2. 按**评分组（子系统）**整理，每组写明满分 + 评分方式（▲ 累加 / 整分判定 / 方案优劣分档）+ 对应 ▲ 范围。
3. **核对各组满分加起来 = 技术总分**（对不上要查）。

## 输出（写入工作区 `## 技术线·评分`，标准 md 表格）
```
| ID | 评分组(子系统) | 满分 | 评分梯度 | 必须材料 | 出处(行号) |
```
ID 用 `T-S001` 起。顶部一行写明技术分合计 = N 个组累加。

## 铁律
评分梯度含"分"字、写清"满足每条▲得X分"；只列事实；**原文数值矛盾不自己拍板**（如表头 3 分 vs 文字 1 分），如实标出来让人核。

# 技术线 · 技术规范偏离（专项工作指南)

## 你的任务
对照招标技术规范书,**逐条**整理技术参数(供投标人填写"满足 / 偏离 / 优于"+偏离说明)。只列事实。

## 输入
- `<项目>.lines.txt`(按行号局部读)
- 技术规范书的章节行号范围(供货要求 / 技术规范书 / 设备清单等)

## 步骤
1. Grep「技术参数 / 技术要求 / 供货要求 / 设备清单」定位。
2. 逐条列参数(参数名 + 招标要求值),原文照搬,不归纳合并。
3. **不要遗漏小数点参数**(频率、阻抗、亮度、分辨率…):这些最容易在 PDF 提取时被切碎,要专门盯。
4. **▲ 标识的参数已经在 ▲ 清单里**,本表只列非 ▲ 的常规参数,避免重复。

## 输出(写入工作区 `## 技术规范偏离对照`,标准 md 表格)
```
| ID | 设备/分项 | 参数名 | 招标要求值 | 出处(行号) | 满足/偏离 | 偏离说明 |
```
ID 用 `T-P001` 起。「满足/偏离」「偏离说明」留空给投标人填。

## 铁律
全量逐条不归纳合并(投标人需要逐项答);维度不绑值;只列事实。

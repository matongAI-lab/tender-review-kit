# 商务线 · 评分（专项工作指南）

## 你的任务
整理商务侧评分项（价格分 + 商务分），逐档列全，让投标人能估算自己能拿多少分。只列事实。

## 输入
- `<项目>.lines.txt`（带行号；按行号局部读，不全读）
- `<项目>.hits.json`（线索）
- 评标办法 / 评分细则的章节行号范围
- `references/disqualification-checklist.md`（看有没有中小企业价扣等政采特有机制）

## 步骤
1. Grep「评标办法前附表 / 价格分 / 分值 / 评分」定位评分细则的行号范围。
2. 局部读，整理：**价格分**（写出计算公式、基准价规则，如"低价优先：最低价满分，余=基准价/报价×满分"）+ **商务分各项**（信用 / 体系认证 / 资质证书 / 项目人员 / 业绩…）。
3. 每项写全评分梯度（**逐档、必含"分"字**：满分条件 / 各档 / 不得分条件）+ 必须材料 + 出处行号。

## 输出（写入工作区 `## 商务线·评分`，标准 md 表格）
```
| ID | 评分项 | 满分 | 评分梯度 | 必须材料 | 出处(行号) |
```
ID 用 `B-S001` 起。顶部一行写明总分构成（价格 X + 商务 Y + 技术 Z = 100）。

## 铁律
评分梯度逐档写全、含"分"字（护栏会查）；只列事实、不评"我方能不能拿到"；维度不绑具体值。

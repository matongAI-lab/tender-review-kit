# 商务线 · 废标排查（专项工作指南）

## 你的任务

产出**商务侧废标项清单**——资格性 / 业绩 / 文件性 / 商务实质性响应 / 商务定制门槛。
**漏一条 = 投标失败**，所以宁全勿漏。你只列事实，不下"投/不投"结论。

## 输入

- `<项目>.lines.txt` — 带行号全文（你唯一的事实来源，引用**必带行号**）
- `<项目>.hits.json` — 判决词撒网结果（**线索池，含噪音**）
- `references/disqualification-checklist.md` — 必拿废标点对照清单
- 招标类型（如 D 类货物）+ 投标人须知 / 评标办法的章节行号范围

## 步骤

1. **筛撒网线索**：读 hits.json 的 `primary`(scope 含 bid_phase/evaluation_phase) + `customization`。
   ⚠️ **逐条语义判断去噪**——撒网宁滥勿缺，你要读上下文区分真假：
   - "无效投标""否决投标""按无效投标处理" = 真废标 ✅
   - "无效数据""拦截无效""统一平台（项目背景）" = 技术功能/背景，不是废标 ❌

2. **对照必拿清单**：通用 15 条 + 本类型特化，**逐条核**。
   招标文件有对应条款 = 纳入；**没有也要标"本招标无此条款"**（不能默认漏）。

3. **读须知/评标办法章节补充**：按给定行号范围实读，补资格性/文件性/商务实质废标
   （报价超限价 / 保证金 / 签字盖章 / 密封逾期 / 工期承诺 / 付款响应 / 异常低价）。

3补. **投标文件递交规格（⭐ 必查，高频漏点）**：从须知"递交/密封"章节固定提取三项——
   **形式**（纸质 / 电子U盘 / 网络平台投标，常并存）、**份数**（正本 N + 副本 M + 电子件）、
   **封装/密封**（分册密封 / 报价是否单独密封 / 封套标记 / 骑缝章）。违反任一多为拒收/废标；
   对照 `disqualification-checklist.md` 的「投标文件递交规格」小节逐条核。

4. **关系门槛**：从 customization 命中里筛**真门槛**（如"第三方软件加盖原厂公章""必须接入现有平台"），
   列为"商务定制门槛"废标——这是最隐蔽的废标点，重点盯。

## 输出

把清单写入工作区文件 `workspace/<项目>.工作区.md` 的 `## 商务线·废标` 节,Markdown 表格:

```
| ID | 类别 | 废标条款 | 出处(行号) | 必须材料 | 核实步骤 |
|----|------|---------|-----------|---------|---------|
| B-D001 | 商务实质性响应 | 投标报价超最高限价=否决 | 行283 | — | 总报价 ≤ 限价金额 |
```

- 类别枚举:`资格性 / 业绩 / 文件性 / 商务实质性响应 / 商务定制门槛`
- ID:`B-D001` 起编(B=商务线,D=disqualification)
- **出处必带 lines.txt 行号**(查漏程序据此反查)
- 核实步骤:投标人怎么自查这一条

### ⭐ 输出结构规范(必读)

**主清单的 Markdown 表格必须放在 `## 商务线·废标` 标题正下方,不要嵌进 `### 子节`**。
说明性内容(撒网命中处置/通用15条对照核验/特化对照/关键发现/流程建议)才用 `### 子节`——
程序识别这些子节会自动跳过其内表格,避免污染主清单计数。

✅ 正确:
```
## 商务线·废标
[可选导语]
| ID | 类别 | ... |   ← 主表格
| B-D001 | ... |
### 撒网命中处置(台账)
[文字 或 不出 sheet 的辅助表]
```

❌ 错误(主表被子节包裹,程序会漏数):
```
## 商务线·废标
### 废标清单(逐项必须自查)   ← 不要套这层
| ID | ... |
```

返回给主对话时，附一句话统计：纳入 N 条、撒网 bid_phase 命中处置情况（纳入 X / 排除 Y 及原因）。

## 铁律

- **全量不压缩**：撒网 bid_phase 命中的**每一条**都要有交代——要么纳入，要么明确写"为何排除（噪音/合同期/重复）"。**不许默默丢**。
- **只列事实不下结论**：列废标条款 + 原文 + 出处，不写"建议投/不投"。
- **维度不绑具体值**：列"业绩证明要求""履约保证金比例"这些**维度**，不假设某个具体年限/平台/比例（那是某项目的实例）。

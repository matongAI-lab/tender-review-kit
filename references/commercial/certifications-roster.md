# 商务线 · 证明文件清册（专项工作指南）

## 你的任务
把投标**要交的全部证明材料**横切聚合成一张清单——投标人照着这张备齐材料、不缺件。只列事实。

## 输入
- 已产出的**废标清单**（看"必须材料"列）+ **▲ 清单**（看"需提供证明"列）+ **评分清单**（逐个评分项看名下要附的证明材料）
- `<项目>.lines.txt`（需要核实材料细节时局部读）

> ⚠️ **别只扫废标+▲两张清单**：人员类证明（项目/技术负责人的资格证书 + **社保缴纳证明**）、信用/体系认证（AAA、ISO 等）、业绩证明，**常常只在评分项里出现**，既不在废标清单也不在 ▲ 清单。漏扫评分清单 = 这类材料整类丢失（本项目曾因此把"社保证明"从聚合清册里漏掉，而早期首版本来扫到了——属回退）。

## 步骤
1. 把废标清单、▲ 清单、**评分清单**里所有"要提供的证明材料"汇总（评分清单逐个评分项点开看名下要附什么材料，尤其人员/资质/业绩类评分项）。
2. **去重 + 按类别归并**：资质证照 / 业绩证明 / 检测报告(CMA·CNAS·ilAC-MRA·IP6X 等) / 认证证书(CCC·3C / ISO / CQC 节能) / **人员证明(资格证书 + 社保缴纳证明)** / 软件著作权 / 原厂公章授权 / 其他。
3. 每条标明来源条款 ID 或行号。

## 输出（写入工作区 `## 证明文件清册`，**必须标准 md 表格**）
```
| 类别 | 材料名称 | 来源(条款ID/行号) | 备注 |
```

> ⚠️ **务必输出成每行 `|` 分隔的标准表格**——否则 `build_excel.py` 转不进 Excel（这是上一版踩过的坑）。不要用"一、二、三 + 列表"的写法。

## 铁律
全量聚合不压缩（▲ 里需检测/认证的都要进）；只列事实。

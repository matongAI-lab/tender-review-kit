# 商务线 · 合同条款要点(专项工作指南)

> **跟「废标项」明确区分**——这是中标**之后**才生效的约束,不是投标递交就废标的硬条款。
> 投标团队可看可不看(很多人投标时不看合同),但工程类/大额项目建议看,中标后会被这些条款罚款/扣款/取消承包资格。

## 你的任务

整理招标文件**合同条款部分**(通常是"第四章 合同条款及格式"或"专用合同条款")中的**关键约束**,产出一份**独立清单**——**不混入废标清单**。只列事实。

## 输入

- `<项目>.lines.txt`(带行号全文,按行号局部读)
- `<项目>.hits.json`(line scope='contract_phase' 命中 + contract 类命中是主线索)
- 合同章节行号范围(通常第四章)

## 步骤

1. 用 Grep 在 lines.txt 找"第四章合同条款"/"专用合同条款"章节行号范围。
2. 看 hits.json 的:
   - `hits.contract` 数组(本份直接命中的合同条款判词,如"不予顺延"/"视为验收通过"等)
   - `hits.primary` 里 scope=contract_phase 的条目(被识别为合同期的强判决词)
3. **只在合同章节行号范围内**实读条款(超出范围的"合同期判词"是 noise)。
4. 按类别整理:

| 类别 | 典型条款 |
|---|---|
| **工期/进度** | 工期不可顺延的情形、关键节点延误处理、延期处罚比例 |
| **工程量/结算** | 工程量按谁审核计算、超量是否调价、缺漏项如何处理 |
| **验收程序** | 验收期限、隐蔽工程默认通过条件、不予签发接收证书的情形 |
| **付款节奏** | 预付/进度/竣工/质保金比例、付款触发条件、滞付罚息 |
| **索赔/答复时效** | 通知方答复时限、X 天未答复视为同意/接受 |
| **担保/扣款** | 履约保证金扣留情形、质量保证金返还条件 |
| **违约责任** | 违约金比例、解除合同情形、取消承包资格条件 |
| **不可抗力** | 不可抗力分摊、不予顺延的例外 |

## 输出

写入工作区 `## 合同条款·要点` 节,**主清单 Markdown 表格放在 `## ` 标题正下方**(不嵌 `### `,程序识别规范):

```
| ID | 类别 | 条款要点 | 出处(行号) | 影响 | 备注 |
|----|------|---------|-----------|------|------|
| B-C001 | 工期/进度 | 检验不合格导致施工费用由承包人承担,工期不予顺延 | 行783 | 中标后:工期延误处罚自负 | — |
```

- 类别枚举:工期/进度、工程量/结算、验收程序、付款节奏、索赔/答复时效、担保/扣款、违约责任、不可抗力
- ID:`B-C001` 起编(B=商务线,C=contract)
- **出处必带 lines.txt 行号**
- **影响**列:写"中标后:XXX",提示投标人这是中标后约束

## 铁律

- **绝不和废标清单混**:废标是"今天废标",合同条款是"中标后罚"
- 全量不压缩:合同章节里的"视为/不予/取消"句式逐条列
- 只列事实:不写"建议谈判"/"建议拒绝"
- 维度不绑值:列「质保期不可顺延的情形」维度,不写「2 年质保不可改」这种具体值

## 返回

摘要:① 合同章节定位(行号范围) ② 合同条款要点 N 条 + 类别分布 ③ 最值得投标人注意的 2-3 条(如"X 天默认接受索赔" / "工期延误违约金比例")。

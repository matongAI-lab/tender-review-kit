# 商务线 · 关键时间节点（专项工作指南）

## 你的任务
列出招标 / 投标 / 评审 / 履约的关键时间节点 + 期限要求,投标人按时按节点行动。只列事实。

## 输入
- `<项目>.lines.txt`（按行号局部读）
- `<项目>.hits.json`（次要参考）

## 步骤
1. Grep「投标截止 / 开标 / 公告 / 答疑 / 质疑 / 异议 / 投标有效期 / 业绩区间 / 公示」定位。
2. 局部读,整理:**投标截止 + 开标**(同一时间?) / **答疑·质疑·异议截止** / **投标有效期**(天数 + 推算到期日) / **业绩时间窗** / **公告发布·公示期**。
3. 同一节点文件里**多处说法不一致**(如异议期 10 天 vs 3 天)——**全部列出来让人核**,不自己拍板。

## 输出（写入工作区 `## 关键时间节点`,标准 md 表格）
```
| 节点 | 时间 | 出处(行号) |
```
若有矛盾,在节点名后加 ⚠并在备注列写明两处不一致。

## 铁律
只列事实;时间冲突如实标注、不自己挑哪个对。
